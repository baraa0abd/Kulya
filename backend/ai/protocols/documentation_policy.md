# Demo documentation workflow policy (SYNTHETIC - NOT A CLINICAL PROTOCOL)

This text was written for software demonstration only. It is not clinical guidance and has not
been reviewed by any clinician. Replace it with clinician-approved protocols before real use.

## Hypotension event documentation

When a hypotension event is recorded during a dialysis session, the record should also contain a
blood pressure reading documented after the event, the nursing action taken with its reason, and
a documented resolution of the event before the session is closed.

## Fluid bolus documentation

When a fluid bolus is recorded as a nursing action, the record should state the reason for the
bolus and include a blood pressure reading documented after it was given.

## Nursing action reasons

Every nursing action recorded during a session should include a documented reason. An action
without a reason is treated as incomplete documentation.

## Treatment duration documentation

When the documented treatment duration differs from the prescribed duration, the session record
should include a nursing note or event that states why the treatment was shortened or extended.

## Session closure documentation

A completed session record should contain pre-treatment and post-treatment weight, pre-treatment
and post-treatment blood pressure, the ultrafiltration volume, and the start and end times.

## Recorded events and resolution

Every event recorded during a session, such as cramps, clotting, a machine alarm, or an access
issue, should have a documented resolution before the session is closed.
